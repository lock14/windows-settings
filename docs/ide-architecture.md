# IDE workspace, multiplexer, and portable shell architecture

This document specifies the runtime mechanics of `bin/ide.ps1` (`bin/ide.cmd` and `libexec/ide/*.ps1`), `config/zellij/`, `plugin/ws-bar/`, `config/nvim/lua/solarized/`, and PowerShell and `cmd.exe` shell integration.

## Frameless Zellij geometry, WASM top shelf, and pane lifecycle

- **Frameless Inverted-T and 2-pane layouts**: All visible IDE panes (`AI`, `Editor`, and `Shell`) live inside a frameless Zellij `0.46+` workspace (`pane_frames false` in `config/zellij/config.kdl`), defaulting to the 3-pane Inverted-T layout (`config/zellij/layouts/ide-3pane.kdl`: top-left AI Agent, top-right Neovim Editor auto-opening `README.md` when present in the launch directory, and bottom full-width PowerShell beneath the 1-line `BASE02` `compact-bar` shelf) or 2-pane side-by-side (`config/zellij/layouts/ide-2pane.kdl` via `--2pane`). `-d` and `--detach` spawn background workspaces (`zellij attach --create-background`), `--desktop` launches a standalone 1-hop GPU desktop window (`zellij terminal --standalone`) without spawning Zellij's background `.desk` daemon, `--new-window` opens a dedicated terminal window, and `--backend wt` provides an automatic Windows Terminal split-pane fallback when Zellij is unavailable.
- **4-layer keybinding isolation**: Windows Terminal (`config/terminal/windows-settings.json`) passes `Alt+*` chords cleanly to Zellij while keeping unmodified printable keys and `Ctrl+h/j/k/l` inside foreground applications (preserving `Ctrl+L` clear, `Ctrl+J` newline, `Ctrl+K` kill line, and `Ctrl+H` backspace in shells and AI CLIs, and keeping `<C-h/j/k/l>` internal to Neovim splits rather than terminal mode `"t"`). `Alt+h/j/k/l` provide universal 2D focus navigation across Zellij, Neovim (`n`, `i`, `v`, `t`), and Vim (`n`, `v`, `i`); `Alt+Shift+H/J/K/L` swap panes directionally; `Alt+Left/Down/Up/Right` resize panes; `Alt+z` toggles zoom; `Ctrl+b r` (`ide refresh`) hot-reloads active sessions; and right-clicking `bar`, `tab`, `pane`, or `common` targets opens the declarative IDE `context_menu`.
- **WASM top shelf and non-destructive pane parking** (`plugin/ws-bar/`): Compiled locally by `setup/` and `bin/update-system.ps1` to `%APPDATA%\Zellij\data\plugins\windows-settings-bar.wasm` (`wasm32-wasip1`, SHA-256 cached in `$HOME\.cache\windows-settings\ws-bar.sha256` with automatic `stable-x86_64-pc-windows-gnu` fallback when Visual Studio C++ Build Tools are absent and `uutils-coreutils` `link.exe` is on `PATH`), pre-seeded in `%LOCALAPPDATA%\Zellij\cache\permissions.kdl`, and bound via `compact-bar location="file:windows-settings-bar"` with automatic fallback to `compact-bar location="zellij:bars"` and geometric `MoveFocus` bindings when unbuilt. Routes zero-spawn `MessagePlugin` `ws-ide-role` messages (`Alt+a`, `Alt+e`, and `Alt+t` focus or bounce, `Alt+Shift+A`, `Alt+Shift+E`, and `Alt+Shift+T` non-destructive pane parking and restoration, and in-place `respawn:ai` via `open_command_pane_in_place_of_pane_id`), renders seasonal holiday emblems, `icd` subdirectory divergence pills, clickable `AI`, `Editor`, `Shell`, `ZOOM`, `SYNC`, `Attention`, `Fleet`, `Monitor`, and `Help` pills, and replaces the right shelf with mode-contextual key hints in `Tmux`, `Resize`, and `Scroll` modes.

## Subcommand CLI surface and direct Named Pipe Neovim RPC

- **16-subcommand CLI and internal plumbing**: `bin/ide.ps1` and `bin/ide.cmd` act as thin entrypoints dot-sourcing focused domain libraries in `libexec/ide/{Core,Rpc,Attention,Fleet,Modals,Workspace}.ps1` on demand across the 16 user subcommands (`list [--plain|--json]`, `switch` or `-s`, `new` or `-n`, `dir` or `-o`, `agent`, `next`, `cd`, `refresh`, `quit [-f|--force]`, `open [-p|--preview]`, `send`, `state`, `ack`, `pr`, `keys`, and `monitor`) plus `ide _internal` for layout initialization, streaming previews, and hook callbacks, honoring `--dry-run` across stateful paths.
- **Direct Named Pipe MsgPack-RPC and socket self-healing** (`.NET NamedPipeClientStream`): Communicates with the workspace Editor over Windows Named Pipes (`\\.\pipe\nvim-ide-<session>`) using in-process `.NET System.IO.Pipes.NamedPipeClientStream` MsgPack-RPC (`libexec/ide/Rpc.ps1`, shared lazily with `v` in `module/Developer.ps1`) with zero external Neovim client spawns. Pipe ownership is restricted strictly to the `Editor` pane via `SolarizedIdeSocket` (`VimEnter` in `config/nvim/lua/solarized/ide.lua`) and `v` `--listen` recovery—never claimed from `Shell`, `AI`, `:terminal`, or `:!` subshell editors. Native `:q`, `:wq`, `:qa`, and `:wqa` remain unremapped; workspace termination runs via `:Q [name...]`, `:Quit [name...]`, `Space q`, `Alt+q`, `qide`, `quit` (`ide quit` checking unsaved buffers over single-RPC `_G.try_ide_quit` via zero-PowerShell `ide.cmd` background dispatch), or `idek` (`ide quit --force`).
- **Working directory healing, lockfile reaping, and 7-hook extensibility**: `opt.autoread = true` and `SolarizedAutoRead` heal stale working directories across `icd` (`ide cd`) and `:IdeCd`, `SolarizedMarkdownReadability` configures `wrap`, `linebreak`, `breakindent`, `scrolloff = 0`, and count-aware `j` and `k` screen-line motion alongside global `opt.scrolloff = 4`, and `config/nvim/` reaps orphaned `%LOCALAPPDATA%\tree-sitter\lock\*.lock` files while healing `reftable` plugin repositories during headless `Lazy.nvim` runs (`-i NONE` and `GIT_DEFAULT_REF_FORMAT=files`). Optional `$HOME\.config\ide\links.ps1` (`$env:IDE_LINK_RULES`) exposes 7 extensibility hooks covering workspace root discovery, custom `ide new` provisioning, subdirectory resolution, URL and short-link rewriting, PR URL resolution, external alert notifications, and directory preview metadata.

## Multi-session fleet switcher, AI supervisor, and lifecycle state machine

- **Responsive fuzzy fleet switcher, workspace launcher, and AI supervisor** (`fzf`): `Alt+s`, `Ctrl+b s`, `Space s`, `ide -s`, or `ide switch` opens the urgency-ranked `fzf` IDE Fleet Switcher across live and saved workspaces, opening the existing-directory picker (`Alt+o`, `ide -o`, or `ide dir` across `zoxide`, `links.ps1` workspace roots, `$env:IDE_WORKSPACE_DIRS`, `$env:IDE_WORKSPACE_PARENT`, and `$HOME` subdirectories with `ide _internal dir-preview`) when zero sessions exist in an interactive TTY, printing `No active IDE sessions.` when non-interactive, and degrading to `ide list` when `fzf` is absent (`ide list --json` serializes structured fleet state). `Alt+n` (`ide -n` or `ide new [name]`) provisions new workspaces via `links.ps1` or `New-Item -ItemType Directory` under `$env:IDE_WORKSPACE_PARENT` or `$HOME`, flipping cleanly with `Alt+o`. On terminals at or above `90` columns (`$SideBySideMinCols = 90`, stacking vertically on `80×24` per [.agents/rules/monospace-tui.md](../.agents/rules/monospace-tui.md)), `--follow` preview workers stream deduplicated ANSI viewport frames (`zellij action dump-screen --ansi` for active sessions or recent Git commits when stopped, labeled `[PREVIEW]` versus `[LIVE]`) alongside `<branch>@<N>` PR badges (`Ctrl+o` or `ide pr`), shared-worktree warnings, `Ctrl+y` (`ide ack`), `Ctrl+x` (`ide quit`), and `Alt+r` (`ide agent [<cli>|restart]`, driving the AI pane supervisor loop and `ws-ide-role` `respawn:ai` `open_command_pane_in_place_of_pane_id` without killing panes on `icd`). `Alt+Shift+S` (`Ctrl+b S` or `ide next`) jumps to the highest-urgency waiting workspace via `GoToNextAttention` or direct attach.
- **Focus-preserving context dispatch** (`ide send`): Visual `Space a` and `Space A` (`--no-focus`), normal `Space il`, `Space if`, `Space ia` (`--no-focus`), and `Space id`, and cross-session `:IdeSend[!] [session]` (`--no-focus` or `--switch`) stage file, line-range, and diagnostic payloads into the AI Agent prompt without overwriting the Windows clipboard, recursively stripping `\x1b[200~` and `\x1b[201~` bracketed-paste escapes and refusing bare idle shells.
- **In-terminal attention and 3-agent lifecycle hooks** (`OSC 7501`): `config/zellij/config.kdl` keeps attention tracking strictly in-terminal (`tray_icon false`, `desktop_notifications` and `tray_badge` disabled, `notification_details false`, `track_commands false`, zero `OpenSessionInTerminal` triggers, and `attention_muted=true` on `Editor` panes). `setup/modules/75-AiHooks.ps1` idempotently wires Antigravity (`$HOME\.gemini\config\hooks.json`), Claude Code (`$HOME\.claude\settings.json` JSON `stdin`), and Codex CLI (`$HOME\.codex\config.toml` `notify` JSON payload) into `ide state <running|approval|quota|done|idle> [-m|--message <text>] [session]` without overwriting unrelated user settings, filtering `idle_prompt` reminders, downgrading `USER_CANCELED` stops to `idle`, suppressing duplicate cross-session alerts in `ws-bar` for the currently active session, and auto-acknowledging attention on pane or session focus (`ide ack`).

## Links, inline images, clipboard, and portable shell parity

- **OSC 8 hyperlinks, cross-pane Alt+Click routing, jumplist marks, and Tree-sitter navigation**: Exports `FORCE_HYPERLINK=1` across PowerShell and `cmd.exe`, keeps `opt.clipboard = "unnamedplus"` without overriding `vim.g.clipboard`, and pairs Zellij `mousebinds` (`Alt Left` `GroupToggle` and `Ctrl Left` `Click` on pane content with `mouse_click_through false` so clicking an unfocused inline `AI` pane never starts an active selection across `\x1b[I` `FocusIn` redraws, dynamically switched by `plugin/ws-bar` to `Alt Left` `Click` whenever `Editor` is focused) with `set_pane_regex_highlights` (`Event::HighlightClicked` on non-Editor panes dispatching `ide _internal open-link` via UTF-16LE `-EncodedCommand`). Clicking `Alt+Click` on file paths, docs (`#anchor` or `:line`), `file://` URIs, OSC 8 links, `links.ps1` rules, or URLs in `AI` or `Shell` panes opens local targets directly in the session's `Editor` (`nvim`) pane over Named Pipe MsgPack-RPC (or launches `nvim --listen` if `Editor` is at an idle shell), while `Alt+Click`, `Ctrl+Click`, and `gx` inside `Editor` traverse Markdown links, `#heading` anchors, images, and autolinks via the Tree-sitter AST (`config/nvim/lua/solarized/links.lua`) before falling back to LSP definitions, recording a single jump mark (`normal! m'`) before `keepjumps` edits so `<X1Mouse>` and `<X2Mouse>` (`Ctrl+O` and `Ctrl+I`) return in one step.
- **Capability-gated inline images**: `config/nvim/lua/solarized/images.lua` configures `snacks.nvim` (`snacks.image`) with all non-image `snacks` modules disabled, `doc = { inline = true, float = false }`, `math = { enabled = false }`, `win_width - textoff` clamping, and silent no-op fallback on terminals that do not support Kitty Graphics `U=1` Unicode placeholders.
- **Streaming VCS prompts and standalone Vim and Command Prompt parity** (`_vimrc` and `autorun.cmd`): Oh My Posh (`config/powershell/p10k_single_line.omp.json`) runs via compiled `$HOME\.cache\powershell\omp_init.ps1` with `"streaming": 150` and `"native_status": true`, refreshing clickable OSC 8 `<branch>@<N>` GitHub pull request and GitLab merge request badges (`_WS_GIT_PR_LABEL` and `_WS_GIT_PR_URL`) asynchronously in the background without blocking prompt rendering. Standalone `config/vim/_vimrc` (`$HOME\_vimrc` and `$HOME\.vimrc`) and native `config/cmd/autorun.cmd` plus `macros.doskey` (`%LOCALAPPDATA%\cmd\`) remain 100% zero-dependency, providing 22-theme `:Theme`, Smart-Home `<Home>`, UTF-8 `BASE02` shelf prompt, `theme_env.cmd`, `mise_paths.cmd`, and `doskey /macrofile` parity when Neovim or PowerShell 7 is unavailable.
