# Visual precision and semantic color architecture

All UI components across Windows Terminal, Zellij, shell prompts, file viewers, and editors adhere to Ethan Schoonover's Solarized Dark specification by default in 24-bit TrueColor (`$env:COLORTERM = 'truecolor'`), while the unified 14-slot semantic role architecture (`base03` through `red`, plus light surface tones `base2` and `base3`) powers all 22 built-in themes and custom user `.theme` definitions via `bin/theme.ps1`, `bin/theme.cmd`, and `libexec/theme/*.ps1`.

The 14 classic daily-driver themes (`solarized-dark`, `solarized-light`, `catppuccin-mocha`, `catppuccin-latte`, `gruvbox-dark`, `gruvbox-light`, `rose-pine`, `rose-pine-dawn`, `everforest-dark`, `tokyonight-night`, `kanagawa-wave`, `dracula`, `nord`, and `onedark`) preserve strict physical hue-to-slot alignment and strictly monotonic `base03` through `base3` neutral ramps. The 8 US Holiday themes (`new-years`, `valentines`, `st-patricks`, `easter`, `independence-day`, `halloween`, `thanksgiving`, and `christmas`) keep the same AST token partitioning and pairwise semantic separation—guaranteeing `GREEN` valid commands, `YELLOW` control flow, and `RED` errors never collide and `MIX_GREEN` and `MIX_RED` retain green versus red diff polarity—while intentionally remapping high-visibility foreground slots and prompt or Zellij emblems to each holiday's signature colors.

## Higher-order architectural pillars

Nine design pillars govern syntax highlighting, Tree-sitter queries, pushdown grammars, terminal chrome, and filesystem styling across all tools:

- **Pillar I: The 3-tier semantic color contract and canvas tranquility**:
  - **Core premise**: Highlighting minimizes cognitive load and saccadic fatigue during code reading, navigation, and review by keeping every palette slot bound to an invariant semantic tier across programming languages, configuration syntaxes, and markup documents:
    - **Tier 1: Monotone ground (70 to 80% screen area) in Base0 and Base01**: Uses `#839496` and `#586E75` for standard text, variable identifiers, parameters, struct and field members, custom domain types and classes (`OrderRecord`, `Context`, `HashMap`, `Instant`, `ClusterNode`, Java and Rust `String`), generic type parameters (`T`), dynamic classes (Python `Callable`, `Union`, `EndpointMetrics`), standard library constructors (`Date`, `Object`, `Math`, `Promise`, `Error`), built-in exceptions (`ValueError`), schema relations (SQL tables, CTEs, views, indexes), Terraform schema blocks, routine and method invocations (`printf()`, `.stream()`), operators, delimiters, comments, and scope qualifiers (`context.`, `fmt.`, `std::`, `boost::`).
    - **Tier 2: Structural anchors (15 to 20% screen area) in Green, Yellow, Blue, and Violet**: Frames structural topology:
      - **Green**: Uses `#859900` for structural scaffolding and declarations (`package`, `func`, `fn`, `def`, `class`, `struct`, `interface`, `var`, `let`, `const`, `typedef`, `CREATE TABLE`, `DEFAULT`, `ASC`, `DESC`), reserved word operators (`sizeof`, `alignof`, `static_assert`), and static primitive types and core built-in scalars (`int`, `double`, `u64`, `usize`, `bool`, `void`, SQL `VARCHAR` and `BIGINT`, Python built-in scalars `int`, `str`, `float`, `bool`, `bytes`, `list`, `dict`, `set`, `tuple`, `object`, `range`).
      - **Yellow**: Uses `#B58900` exclusively for control flow and jumps (`if`, `else`, `return`, `for`, `while`, `switch`, `case`, `select`, `defer`, `match`, `try`, `catch`, `throw`, `yield`, `await`, `CASE`, `WHEN`), ensuring branch points and jump exits command peripheral attention uncontested by types, keywords, or headings.
      - **Blue**: Uses `#268BD2` for routine and function declarations (`func New...`, `fn find...`, `def __init__`), diff hunk headers (`@@ ... @@`), and Markdown H2 section boundaries.
      - **Violet**: Uses `#6C71C4` for declarative metadata, annotations, decorators, attributes, imports, and modules (`@Service`, `@dataclass`, `#[derive]`, `[[nodiscard]]`, `import`, `from`, `use`, `package main`, `@module`, Markdown H3).
    - **Tier 3: Values and directives (5 to 10% screen area) in Cyan, Magenta, and Orange**: Highlights literals and directives:
      - **Cyan**: Uses `#2AA198` for string literals, filesystem paths, unbroken escape sequences and format specifiers (`%s`, `\n`), raw backtick struct tags, and Markdown link targets.
      - **Magenta**: Uses `#D33682` for numeric literals, booleans (`true`, `false`), named `ALL_CAPS` and `iota` constants (`EXIT_FAILURE`, `MAX_BUFFER_SIZE`, `LevelDebug`), host environment globals (`console`, `process`, `globalThis`, `window`, `document`), regex literal bodies, and sentinel values (`nil`, `null`, `None`, `std::nullopt`, `_`, `this`, `self`).
      - **Orange**: Uses `#CB4B16` for compiler directives, preprocessor macros (`#define`, `#include`), interpreter shebangs (`#!/bin/bash`), and Markdown H1 titles.
  - **Two-tier configuration topology**: In TOML, section headers (`[table]`, `[[array]]`) receive Blue (`#268BD2`) while internal mapping keys (`port =`, `pool.min_size =`) receive Green (`#859900`), keeping brackets (`[`, `]`, `[[`, `]]`), dots (`.`), and equals signs (`=`) in Base0 (`#839496`).
  - **Temporal scalar invariance**: Unquoted TOML RFC 3339 timestamps (`2025-09-14T08:30:00Z`, `17:45:00`) belong to Magenta (`#D33682`) alongside numbers and booleans rather than Cyan strings.
  - **Declarative configuration continuum**: XML and HTML tag attribute names (`xmlns`, `version`, `id`, `replicas`, `lang`, `class`, `charset`, `data-status`) receive Green (`#859900`), tag delimiters (`<`, `>`, `</`, `/>`) remain in Base0 (`#839496`), element tag names belong to Blue (`#268BD2`), and attribute string values remain in Cyan (`#2AA198`).
  - **Stylesheet hierarchy (CSS)**: At-rules (`@layer`, `@font-face`, `@keyframes`, `@container`, `@media`, `@supports`) belong to Orange (`#CB4B16`); optional `@container` names and units (`px`) sit in Base0 (`#839496`) with dimensions in Magenta (`#D33682`). Selectors (`body`, `*`, `.card-grid`, `#dashboard-grid`) receive Blue (`#268BD2`), `&` and attribute names (`["@tag.attribute.css"]`) sit in Base0, attribute strings receive Cyan (`#2AA198`), pseudo-classes and pseudo-elements (`:root`, `:hover`, `::before`) receive Violet (`#6C71C4`), property names receive Green (`#859900`), custom properties (`--color-base03`), functions (`var()`, `oklch()`, `clamp()`), and compound keywords (`auto-fill`) sit atomically in Base0, hex colors (`#002b36`) sit atomically in Magenta (`#D33682`), and leaf overrides inside compound selector blocks specify priority `>= 130`.
  - **Java Properties**: Keys (`spring.application.name`, `server.port`) receive Green (`#859900`), assignment delimiters (`=`, `:`) and interpolation wrappers and keys (`${spring.application.name}`) sit in Base0 (`#839496`), numbers and booleans receive Magenta (`#D33682`), strings and escapes remain unified in Cyan (`#2AA198`), and comments (`#`, `!`) sit in Base01 (`#586E75`).
  - **Protocol Buffers** (`.proto` and `.textproto`): `syntax` and `edition` directives receive Orange (`#CB4B16`); `import` and declared `package` namespace identifiers (`telemetry.v1`) receive Violet (`#6C71C4`); `package`, structural schema keywords (`message`, `enum`, `oneof`, `service`, `rpc`, `returns`, `option`, `extend`, `reserved`, `to`, `max`, `map`, `repeated`, `optional`, `required`, `stream`, `public`, `weak`), and built-in scalars receive Green (`#859900`); `rpc` method names receive Blue (`#268BD2`); user-defined types, package qualifiers, and field identifiers sit in Base0 (`#839496`); enum constants, field tag numbers, unified negative numbers (`-1`), and booleans receive Magenta (`#D33682`). In `.textproto`, message block headers (`recorded_at {`, `route_quotas <`, `metrics: [{`) receive Blue (`#268BD2`), scalar field keys (`["@property.textproto"]`) receive Green (`#859900`), bracketed extension and `Any` type URLs receive Violet (`#6C71C4`), and numbers, `inf`, `-inf`, `nan`, booleans, and enum values receive Magenta (`#D33682`).
  - **Markdown semantic architecture**: Across Tree-sitter (`@markup.heading.1..6.markdown`) and `render-markdown.nvim` (`RenderMarkdownH1..H6`, `RenderMarkdownH1Bg..H6Bg` on `base02` `#073642` with `bold = false`): H1 Orange (`#CB4B16`), H2 Blue (`#268BD2`), H3 Violet (`#6C71C4`), H4 Base1 (`#93A1A1`), H5 and H6 Base0 (`#839496`), with `#`, `>`, and `|` sigils in Base01 (`#586E75`), callouts (`[!NOTE]` Blue, `[!TIP]` Green, `[!IMPORTANT]` Violet, `[!WARNING]` Orange, `[!CAUTION]` Red—never Yellow), checkboxes (`[x]` Green, `[ ]` Base01), `pipe_table` `style = "normal"`, `cell = "raw"`, and `wrap = false`.
  - **Pure monospace typography and monochromatic chrome**: Code tokens strip bold (`bold = false`). Inactive `LineNr` uses Base01 (`#586E75`), active `CursorLineNr` uses Base1 Bold (`#93A1A1`) on `base02` (`#073642`), `WinSeparator` and `FloatBorder` remain in Base01, `MatchParen` uses Base1 on Base02 without syntax mutation, `Search` uses `mix_yellow`, `Visual` uses `mix_base1`, and diagnostics use Error Red, Warn Yellow, Info Blue, and Hint Cyan with `fg = "NONE"` on `DiagnosticUnderline*`.

- **Pillar II: Operational role invariance**:
  - **Definition versus invocation**: Declarations (`func Process()`) are Blue (`#268BD2`); invocations (`node.Process()`, factory calls such as `NewClusterNode`, and built-ins such as `panic(...)`, `make(...)`, `len(...)`, `printf(...)`) remain in Base0 (`#839496`), never flipping to Yellow.
  - **Contextual disambiguation**: Receiver references (`this.timeoutMs`, `self.val`, `super.init()`) are Magenta (`#D33682`), while constructor delegation calls (`this(...)`, `super(...)`) are Base0; computed member keys (`[Symbol.iterator]()`) evaluate on their native expression tiers rather than Blue; host globals (`console`, `process`, `globalThis`, `window`, `document`) are Magenta while their methods (`.log()`) are Base0; sentinels (`NULL`, `None`, `nil`, `_`, `std::nullopt`) are Magenta; and Terraform block headers (`provider "aws" {`) are Green while assignment keys (`provider = aws.west`) are Base0.

- **Pillar III: Gestalt semantic continuity and atomic compound enclosure**:
  - Strings, escapes (`\n`), format placeholders (`%s`, `:.4f`), and Go backtick struct tags remain unified in Cyan (`#2AA198`); regex bodies remain unified in Magenta with Base0 slashes and Cyan flags; compound attributes (`#[derive(...)]`, `#![no_std]`, `[[nodiscard]]`, `@dataclass`, `@Override`, `@file:JvmName`, `@available`) remain unified in Violet (`#6C71C4`); Rust lifetimes (`'a`, `'static`) remain unified in Green (`#859900`); and diff `+` and `-` lines form single semantic mutations in Green or Red, enhanced in `delta` via `MIX_GREEN` and `MIX_RED` subtle line backgrounds.

- **Pillar IV: Navigational neutrality**:
  - Scope qualifiers (`std::`, `boost::`, `context.`, `fmt.`), PowerShell `$` variable prefixes, shell expansion sigils (`$`, `${`, `}`, `$(...)`), and interpolation delimiters (`${`, `}`, `~`, `%{`) remain in Base0 (`#839496`), while formal module declarations receive Violet (`#6C71C4`) and HCL root scope keywords (`var.`, `local.`, `terraform.`, `data.`, `module.`) receive Green (`#859900`).

- **Pillar V: Pushdown automata state machine engineering** (`config/bat/syntaxes/*.sublime-syntax`):
  - The 37 grammars in `config/bat/syntaxes/` covering the 40-language polyglot suite (`tests/fixtures/sample-code/`) must remain 100% standalone without external TextMate `Packages/...` includes, consume opening delimiters on context push rather than trapping lookaheads, anchor indentation-sensitive statement headers with `^\s*` and `(?!\s*[=:])`, deconstruct composite operators (`2>&1`), isolate `case` arms, guard contextual keywords (`of`, `in`, `catch`, `finally`, `value`, `data`) with `(?<!\.)` and lookaheads, push autonomous expression contexts on computed `[...]`, and partition dotted TOML keys via lookaheads.

- **Pillar VI: Tree-sitter AST query hierarchy** (`config/nvim/queries/` and `config/nvim/after/queries/`):
  - Across the 43 `.scm` files, root capture groups mirror the universal color contract (`@function.call` maps to `Base0`, `@keyword.import` maps to `Violet`, and `@variable.builtin` maps to `Magenta`); compound leaf delimiters require `#set! priority 130`; canvas resets bind to concrete Base0 captures (`@markup.raw.block`, `@variable`, `["@markup.raw.xml"]`) rather than transparent `@none`; language injections guard on explicit attributes (`type="text/javascript"`); rogue `(#set! "url"` metadata is superseded across the 13 base queries in `config/nvim/queries/` without `;; extends` (`css`, `dockerfile`, `elixir`, `graphql`, `html`, `html_tags`, `lean`, `markdown_inline`, `properties`, `proto`, `rego`, `textproto`, and `xml`, paired with 30 runtime extensions in `config/nvim/after/queries/` with `;; extends`); never maintain both `queries/<lang>/` and `after/queries/<lang>/` for the same query file; and generic catch-all rules precede specialized `#lua-match?` rules in document order.

- **Pillars VII through IX: Standalone subsystem currency, 4-layer terminal depth, and filesystem parity**:
  - `mise.toml` and `configuration.dsc.yaml` declaratively pin LTS and stable polyglot toolchains, language servers, and Rust and Go CLI tools (`bat`, `delta`, `dust`, `elan`, `eza`, `fd`, `fzf`, `gh`, `glow`, `go`, `java`, `jq`, `maven`, `neovim`, `node`, `npm:bash-language-server`, `npm:pyright`, `npm:typescript`, `npm:typescript-language-server`, `npm:vscode-langservers-extracted`, `npm:yaml-language-server`, `python`, `ripgrep`, `rust`, `sd`, `shellcheck`, `tealdeer`, `terraform`, `tree-sitter`, `yq`, `zellij`, `zoxide`).
  - Terminal surfaces preserve 4 depth planes: Layer 0 (`BASE03` ground), Layer 1 (`BASE02` shelves across Oh My Posh, `autorun.cmd`, and `ws-bar` plus `BASE01` borders and `BASE00` `\uE0B1` and `\uE0B3` chevrons leading into `\uE0B0` and `\uE0B2` caps), Layer 2 (`BASE0` monotone ground and calm OS icon with seasonal `_HS_PROMPT_OS_ICON` overrides during US Holiday themes), and Layer 3 (semantic accents).
  - Filesystem color precedence flows from explicit globs in `config/colors/LS_COLORS` over explicit globs in `EZA_COLORS` over 2-letter family codes: `.ps1`, `.psm1`, and `.psd1` PowerShell files remain in calm `BASE0` ground alongside source files, directories map to Blue (`34`), executables to Green (`32`), symlinks to Cyan (`36`), archives to bright slot 9 (`91` Orange), media files to bright slot 13 (`95` Violet), and cryptographic keys and certificates (`.key`, `.pem`, `.crt`, `cr`) to slot 5 (`35` Magenta).

## Tooling implementations

- **Unified theme engine** (`bin/theme.ps1`, `bin/theme.cmd`, and `libexec/theme/*.ps1`): Manages the 22 built-in `.theme` definitions in `config/themes/` plus user themes in `$HOME\.config\windows-settings\themes\` (`--create <slug> [--from <base>]`), supporting `--list`, `--plain`, `--current`, `--set`, `--preview`, `--holiday` (`$env:THEME_HOLIDAY_DATE`), `--sync-assets`, `--check-assets`, `--no-live`, `--dry-run`, and responsive `fzf` TrueColor previews. Live-updates Windows Terminal JSON Fragments (`config/terminal/windows-settings.json` and `settings.json`), Zellij (`config/zellij/themes/windows-settings.kdl`, bounded `tray_badge_colors` and `terminal` blocks in `config.kdl`, and live `ws-ide-state` broadcasts), terminal OSC 4, 10, 11, and 12 slots, running Neovim Named Pipe servers (`\\.\pipe\nvim*`), Oh My Posh (`p10k_single_line.omp.json` with `$env:POSH_SESSION_ID` cache rotation and `ServeProcess` reload), `theme_env.ps1`, CRLF-safe `theme_env.cmd`, `bat`, `delta`, `btop4win`, `tealdeer`, `fzf`, `eza`, `jq`, and `LS_COLORS`.
- **Syntect CLI viewers** (`bat` or `b`, and `delta`): Compiles all 22 `config/bat/themes/*-TrueColor.tmTheme` palettes and 37 `config/bat/syntaxes/*.sublime-syntax` grammars via `bat cache --build` to `%APPDATA%\bat\`, pairs with `config/git/delta.gitconfig`, and leaves `cat` unwrapped for `uutils-coreutils` `cat.exe`.
- **Neovim and standalone Vim** (`config/nvim/` and `config/vim/_vimrc`): Modular `lua/solarized/theme*.lua` engine, Native 0.11+ and 0.12+ LSP (`vim.lsp.config`), 43 Tree-sitter `.scm` queries, `render-markdown.nvim` (`Space m`), capability-gated `snacks.nvim` inline images (`images.lua`), `mini.files` (`Space e` and `Space E`), and zero-dependency standalone 22-theme `config/vim/_vimrc` (`$HOME\_vimrc` and `$HOME\.vimrc`).
- **Shells, terminal fragments, and CLI monitors**: PowerShell `WindowsSettings` and PSReadLine syntax tokens, Oh My Posh (`config/powershell/p10k_single_line.omp.json`), native `cmd.exe` (`config/cmd/autorun.cmd`), Windows Terminal Fragment (`config/terminal/windows-settings.json`), `btop4win` (`config/btop/btop.conf` and 22 themes), and `tealdeer` (`config/tealdeer/config.toml`).
